# 路线费用核销台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在车辆调度小工具基础上扩展的路线费用核销闭环，数据保存在浏览器 localStorage。

## 业务流程

1. **派车单登记**：路线、车牌、司机、时段、预计里程、桥费上限、应缴/实缴押金。
   - 放行闸口（任一不过即「待放行」，页面显示触发条件与差额）：
     - 预计里程低于该路线历史最低里程；
     - 桥费上限缺失（未设置 > 0 的约束）；
     - 押金未缴足。
   - 闸口通过即放行（「待回场」），同时冻结预算快照（油费 = 里程 × 2 元/km，桥费 = 桥费上限）。
2. **回场录入**：起止里程与票据明细（油费/桥费/其他）。
   - 票据缺失、桥费票据超桥费上限、实付超预算一成（预算 × 1.1）或里程异常 → 自动转「待复核」，并列明触发条件与差额。
3. **补录修订**：待复核单据补录正确数据并**填写原因**，提交后生成一条修订（旧/新实付、票据张数、原因、时间）；**原预算快照保留可查**，不被覆盖。补录后满足条件即转「已核销」。
4. 回场里程会回写路线历史最低值，作为后续派车单的校验基准。

## 分层结构

- `src/types.ts`：数据模型（派车单、预算快照、回场、票据、修订、路线基准）。
- `src/rules.ts`：判定层，纯函数（闸口校验、核销判定、金额/里程计算），不依赖 Vue 与存储。
- `src/store.ts`：数据层，Pinia + localStorage，负责任务、预算、票据、修订的一致性持久化与状态流转。
- `src/components/`、`src/App.vue`：页面层，只负责交互与展示。
